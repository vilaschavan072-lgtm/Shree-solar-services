# Shree Solar Services Android app

A native Android starter app built with Kotlin and Jetpack Compose.

## Included
- English, Marathi and Hindi language switch inside the app
- Solar energy information
- PM Surya Ghar scheme information with official portal link
- MNRE official website link
- Customer enquiry form that prepares a WhatsApp message
- Tap-to-call and WhatsApp contact for +91 95618 01599

## Build an APK
1. Install Android Studio (current stable version).
2. Open this folder in Android Studio.
3. Allow Gradle sync and install the Android SDK platform 35 if prompted.
4. Select **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
5. Android Studio will show the APK location.

## Important
This is a starter app project, not a precompiled APK. It has not been built or tested on a device in this environment. Scheme content is introductory; always verify current eligibility and subsidy amounts on official government portals. The app does not provide live scheme feeds or admin publishing yet.
